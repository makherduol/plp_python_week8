# Personal Mini-Toolkit

### What This Toolkit Does
This project provides an interactive command-line application featuring three helpful utilities:
1. **Number Guessing Game**: Challenges the user to find a hidden number with dynamic feedback hints.
2. **Dynamic Todo List**: Allows users to add and view tasks that persist dynamically during the active session.
3. **Simple Tip Calculator**: Computes service-based tip percentages and total bills cleanly.

### How to Run It
Make sure you have Python installed, then run the script from your terminal:
```bash
python toolkit.py
